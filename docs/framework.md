# Framework

## Purpose

本プロジェクトは、2055年の日常生活を描いた短編ストーリーから出発し、固定した
量子探索基盤がどのような製品、サービス、利用場面、社会条件へ派生するかを議論する。
技術基盤は運営側が固定し、参加者は利用者、日常変化、副作用、別の派生を検討する。

## Guiding question

> 2055年に実用的なGrover系量子探索が利用可能であるとき、その探索機能はどのような
> 製品・サービスへ組み込まれ、誰のどの日常活動を変えるか。

2055年は外部予測ではなく、比較のために固定する `project_scenario` である。

## Common quantum-search baseline

共通基盤に含めるアルゴリズムは、Grover search、quantum amplitude amplification、
threshold search、Grover-based quantum minimum findingである。QAOA、量子アニーリング、
量子センシング、量子化学、量子通信は共通基盤に含めない。

「量子計算で最適化する」という表現だけで済ませず、候補表現、制約判定、評価値判定、
振幅増幅、測定、古典検証、エンドツーエンド比較を定義する。

## Derivation method

派生マップは、量子アルゴリズム、実行方式、問題定式化、アプリケーション機能、
製品・サービス、利用者活動、生活変化、社会要件、副作用、未解決の問いを接続する。
技術名ではなく、一人の活動・判断・負担がどう変わるかを中心に記録する。

量子計算だけでなく、データ、古典システム、運用組織、制度、インフラ、利用者との
関係を明示する。ストーリーは一人の中心人物、一つの主要活動、一つの生活変化に絞り、
技術説明より人物の日常活動を中心にする。

## Terminology

| Term | Meaning |
|---|---|
| Project scenario | 外部予測ではなく議論用に固定した未来条件 |
| Utility | 計算価値が構築・運用・実行の総費用を上回る状態 |
| Hybrid execution | 古典処理と量子探索を組み合わせた方式 |
| Quantum-dominant execution | 探索の計算核を主として量子回路内で実行する方式 |
| Derivation map | 工学基盤から製品・生活・社会への派生構造 |
