# Story 1 scene images

The page uses the four production WebP images in this directory:

- `scene-1.webp`
- `scene-2.webp`
- `scene-3.webp`
- `scene-4.webp`

The corresponding source PNG files are kept alongside them as `scene-1.png` through
`scene-4.png`.

The page provides a styled fallback when an image is absent. Images should use the same aspect
ratio and composition as the versions used to tune the percentage-based hotspot coordinates in
`site/explore/story-1/story-1.js`.
